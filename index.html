Privacy Policy

Health Hub · personal WHOOP integration · Effective 18 October 2026

Health Hub is a personal, self-hosted app that runs on one computer and has one user: the person who built it, Mustafa Tariq. Its WHOOP integration lets that person see their own WHOOP data alongside the rest of their health records. It is not offered to anyone else, and nobody else can create an account or sign in.

What WHOOP data it can access

When the WHOOP account is connected, WHOOP grants the app permission (scopes) to read:

  • Profile: first and last name (read:profile)
  • Body measurements (read:body_measurement)
  • Physiological cycles (read:cycles)
  • Recovery (read:recovery)
  • Sleep (read:sleep)
  • Workouts (read:workout)
  • Offline access (offline), so access can be renewed without signing in to WHOOP again

At present the app actually retrieves only the basic profile name, and only when its owner chooses Test the connection. The name is shown once on screen and is not saved. The app never writes or changes anything in the WHOOP account. If features that import sleep, recovery, cycle, workout or body data are added, this policy will be updated before they are used.

Where it is stored

  • Everything stays on the owner's own computer. The app has no cloud database or hosted server, and by default it only answers requests made on that computer, from its owner's signed-in account.
  • The access token and refresh token WHOOP issues are kept in a private file in the app's data folder on that computer. They are never sent to the web browser or to any other service.
  • The app's WHOOP client secret is kept in a local configuration file and used only by the app's server.
  • Requests to WHOOP are made directly from that computer to WHOOP's API over HTTPS.
  • The token file is protected by access to the computer itself; it is not separately encrypted. Backup copies the owner makes of the app's data folder may include it.
  • The app keeps no logs of requests or tokens.

How it is used

  • Only to show the owner's own WHOOP data to the owner, inside Health Hub.
  • Not sold, shared, rented or disclosed to anyone.
  • Not used for advertising, analytics, profiling or training any model.
  • No third-party services, trackers or cookies receive WHOOP data.

How long it is kept

An access token is valid for about an hour and is renewed automatically while the account stays connected. Tokens are kept until the WHOOP account is disconnected, or until WHOOP stops accepting them, at which point the app deletes them.

How to disconnect and delete it

  • In Health Hub, open Health → Settings → WHOOP and choose Disconnect. The app asks WHOOP to revoke its access (WHOOP's revoke endpoint) and deletes the stored tokens from the computer.
  • To remove everything, also delete the app's WHOOP configuration (client ID and secret) and any backup copies of its data folder.
  • Data held by WHOOP itself is governed by WHOOP's own privacy policy.

Changes

If the integration changes what it accesses or how it handles data, this page will be updated and its date changed.
